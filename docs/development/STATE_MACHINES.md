# 0-infinity State Machines

Mandate runtime:

```text
ARMED → TRIGGERED → VALIDATING → SUBMITTING → ACKNOWLEDGED → PARTIALLY_FILLED → FILLED
```

Terminal/side transitions:

```text
ARMED → EXPIRED | SUPERSEDED | INVALIDATED
TRIGGERED → INVALIDATED
VALIDATING → REFUSED
SUBMITTING → FAILED | UNKNOWN
ACKNOWLEDGED → CANCELLED
PARTIALLY_FILLED → FILLED | CANCELLED
```

Development state:

```text
DISCOVERED → PROPOSED → REVIEWING → APPROVED → IMPLEMENTING → IMPLEMENTED_LOCAL → TESTING → EVIDENCED → REVIEWED → INTEGRATED
```
