# Final demo media package

This directory contains the mechanism-led demo candidate and the small set of
inputs needed to reproduce it locally. Alternate renders, intermediate clips,
scene dumps, and superseded voiceovers are intentionally not submission
artifacts.

## Files

| File | Role |
|---|---|
| `0-infinity-mechanism-led-candidate.mp4` | Rendered 1920×1080 H.264/AAC candidate; 136.858 s in the checked artifact |
| `0-infinity-voiceover-locked.mp3` | Locked narration input; 136.908 s, mono MP3 |
| `demo.png`, `integrate.png`, `try.png` | UI proof-surface inputs used by the renderer |
| `landing.png` | Additional landing-route evidence frame |
| `qa-start.png`, `qa-mechanism.png`, `qa-proof.png`, `qa-end.png` | Human-review checkpoints |
| `0-infinity-mechanism-led-qa.json` | 1 fps frame-difference receipt generated by `qa_motion.py` |

The renderer also requires FFmpeg, FFprobe, and DejaVu Sans / DejaVu Sans Bold
at `/usr/share/fonts/truetype/dejavu/`. The renderer itself generates temporary
scene clips under `.tmp/mechanism-led-candidate/`; that directory is not part
of the package and should not be committed.

## Reproduce and verify

From the repository root:

```bash
python3 render_mechanism_film.py
python3 qa_motion.py
ffprobe -v error -show_entries format=duration,size:stream=codec_name,codec_type,width,height -of default=noprint_wrappers=1 docs/submission/media/final/0-infinity-mechanism-led-candidate.mp4
```

The render is deterministic for a fixed FFmpeg version, font files, and input
hashes. The final mux uses the locked narration duration and `-shortest` rather
than a stale hard-coded duration. `qa_motion.py` uses only Python's standard
library plus FFmpeg; it writes the JSON receipt and fails if frames cannot be
decoded.

This is a local candidate, not deployment or upload evidence. The repository
does not claim that a submission destination accepted this file.
